# Кодування Шеннона-Фано

Покрокова візуалізація алгоритму Шеннона-Фано на React + TypeScript.

- Введіть будь-який текст — частоти символів рахуються автоматично.
- Дерево будується крок за кроком: «Далі» / «Назад», автоплей і повзунок.
- Таблиця кодів із порівнянням рівномірного коду та коду Шеннона-Фано.
- Середня довжина коду L, ентропія H, ефективність H / L, коефіцієнт стиснення.
- Закодований рядок обома способами.

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/shannonFano.ts` — алгоритм, рівномірний код, статистика
- `src/TreeView.tsx` — SVG-дерево
- `src/App.tsx` — інтерфейс і порівняння
